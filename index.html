This bot is one HTML file with no server and no API key, so it can be hosted almost anywhere for free.

Route A · Moodle file5 min

  1. Save the bot as index.html.
  2. In your Moodle course: Turn editing on → Add an activity or resource → File.
  3. Upload index.html. Under Appearance, set Display to Open or In pop-up.
  4. Save. Students click it and the bot runs in their browser.

Route B · GitHub Pages linkBest for Teams

  1. Create a free GitHub account and a public repository, e.g. novabot.
  2. Add file → Upload files → drop in index.html → Commit.
  3. Settings → Pages → Source: Deploy from a branch, branch main, folder / (root) → Save.
  4. After a minute you get https://yourname.github.io/novabot/.

Put the link in Teams

  1. Open the class team → channel → + (Add a tab) → Website.
  2. Name it “NovaBot”, paste the GitHub Pages URL, Save.
  3. Or simply post the URL in the channel and pin it.

Put the link in Moodle

  1. Add an activity or resource → URL → paste the link.
  2. Optional: inside a Page, use the HTML editor to embed <iframe src="…" width="100%" height="650"></iframe> if your Moodle allows iframes.

Update the answers

  1. Open index.html in any text editor.
  2. Edit the POLICY block or a rule's reply text.
  3. Re-upload. Moodle and GitHub Pages show the new version.

Next level for the bonus track: replace the IF/THEN rules with an AI model (for example Microsoft Copilot Studio inside Teams). Check your institution's licence first; the rule-based version needs none.
